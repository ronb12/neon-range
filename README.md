# Neon Range

A seated WebXR laser gallery. Clear the plates. Keep the combo. Leave the no-shoot marks alone.

## Assets (CC0)

All third-party art is from [Kenney](https://kenney.nl), public domain (CC0):

- [Blaster Kit](https://kenney.nl/assets/blaster-kit) — `blaster-g` laser, targets, crates
- [Space Station Kit](https://kenney.nl/assets/space-station-kit) — bay walls, floors, rails, consoles
- [Prototype Textures](https://kenney.nl/assets/prototype-textures)
- [Sci-Fi Sounds](https://opengameart.org/content/sci-fi-sounds) — laser and impact one-shots

Attribution is appreciated, not required.

## Play

```bash
npm install
npm run dev
```

Chrome or Edge at `http://localhost:43177`. Enter VR with a connected headset, or play on desktop.

## How it plays

3-2-1, then 45 seconds. Laser leaves the barrel. Hits flash and hang a score. Misses scorch the back wall. Gold pays more. Rush plates charge you. Marked plates dump the combo.
